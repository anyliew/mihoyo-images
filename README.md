# 米哈游图片素材仓库文档

## 项目简介

`mihoyo-images` 是一个用于整理米哈游相关角色图片素材的仓库。当前素材主要存放在 `normal-character` 目录下，按角色名称建立子目录，图片格式以 `webp` 为主，少量为 `png`。

本仓库适合用于素材归档、角色图片检索、格式转换和学习交流。

使用前请阅读文末的版权与使用限制。

    │   ├── 角色名Gu1.webp
