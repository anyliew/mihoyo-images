
# 原神游戏-角色面板图库

这是一个自动归档与收集《原神》游戏内角色面板（“角色-属性”界面）截图的仓库。

## 🌟 仓库特点
*   **原始归档**：保留最原始的游戏内截图，真实反映角色属性与面板。
*   **按角色归档**：每位角色拥有独立的文件夹，并以中文角色名命名，查找直观。
*   **自动命名**：图片采用 `角色名X.webp` 的自动化命名格式，便于程序处理与排序。
*   **持续更新**：随着游戏版本更新与新角色实装，此仓库会持续收录新的面板图。

## 📁 目录结构说明




```
genshin-img/
├── normal-character/ # 主目录：存放所有可玩角色的截图
│ ├── 七七/ # 以角色命名的独立文件夹
│ │ ├── 七七1.webp # 图片命名格式：`角色名` + `` + `序号`
│ │ ├── 七七2.webp
│ │ └── ...
│ ├── 刻晴/
│ └── ... # 其他所有角色
└── README.md # 本说明文件

```




**命名解析**：
*   `` 前缀：代表此类图片为游戏内“角色-属性”界面（即“面板”）的截图。
*   数字序号：通常代表同一角色的不同时期、不同装备配置或不同账号下的截图记录。

## 🚀 如何使用
1.  **浏览**：进入 `normal-character/` 目录，找到你想查看的角色文件夹。
2.  **下载**：直接点击图片，在GitHub预览页使用右键“图片另存为”即可下载。
3.  **引用**：如需在项目、攻略或视频中引用，请保留本仓库出处链接。

*   **内容说明**：本仓库所有图片均为《原神》游戏内截图，版权归属于米哈游（miHoYo）。
